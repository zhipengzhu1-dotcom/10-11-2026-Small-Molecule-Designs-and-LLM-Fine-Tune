# Table 9. s1K sample from s1-prob

Label: `tab:prob` (main.tex L974-L1416, appendix D.2, a `longtable`)

One full s1K training sample from s1-prob, the Stanford statistics qualifying exam source in Table 7. It is
text, not data. The layout has one column and three blocks:

1. The question (black). It gives integrable random variables X, Y_0 and Z_0 and two sigma-algebras A and
   B. Y_k is the conditional expectation of X given A and Z_0 to Z_(k-1), and Z_k the same given B and Y_0
   to Y_(k-1). Part (a) asks to show that Y_n and Z_n converge in L1 to some Y_infinity and Z_infinity.
   Part (b) asks to prove that Y_infinity = Z_infinity almost surely.
2. The reference solution (yellow). Part (a) uses filtrations. Part (b) gives two proofs, which use the
   tower property and Levy's upward theorem.
3. The reasoning trace (light blue) and response (blue), both generated by Gemini from the question alone.
   The response ends with the boxed answer "Y_infinity = Z_infinity".

Reading notes:

- s1K stores each sample as question, solution, Gemini reasoning trace and Gemini response. This table shows
  that layout. Training uses only the trace and response as targets (C-152).
- The solution contains its own `\label{tower}` for an equation, so the check names the table by the label
  after its caption.
- Claims: C-160.
